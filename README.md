# React Posts (API Fetching)

A React + Vite app from **Advanced Full-Stack Web Development (DPRG507)**. It fetches posts from the [DummyJSON](https://dummyjson.com/posts) REST API and renders them, with loading and error states.

## Concepts
- `useEffect` + `fetch` with async/await
- `AbortController` cleanup to cancel in-flight requests on unmount
- HTTP status checks and error handling
- Loading, error and empty states
- Component styling with CSS

## Run it
```bash
npm install
npm run dev
```
**Stack:** React · Vite · JavaScript · REST APIs
